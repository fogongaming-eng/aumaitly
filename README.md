# Aumaitly — site public

Pages publiques d'Aumaitly, servies par GitHub Pages :

- `index.html` : accueil (lien exigé par l'écran de consentement Google) ;
- `confidentialite.html` : politique de confidentialité, dont l'usage des données reçues des API Google ;
- `conditions.html` : conditions d'utilisation ;
- `mentions-legales.html` : éditeur et hébergeur.

Aucun code de l'application ici : le dépôt de l'application reste privé.
